## Findings with original attribution and reproductions

### E1 — Medium: Aggregate contradiction verdict does not control multiplicity
**Attribution:** This evidence/statistical reviewer.

**Source:** `src/evidence.mjs:266,274,293–294`.

Each component receives an unadjusted lower-tail contradiction test at `alpha`. The overall hypothesis becomes `contradicted` when **any** component is contradicted. Unlike requiring every component to support the hypothesis, selecting any contradiction introduces multiplicity.

**Minimal trigger:** A valid registration with 32 arms, 32 presence claims, five replicas, `probability: 0.5`, and `alpha: 0.05`. Each claim tests its corresponding arm’s statistic against zero. Supply five negative contrasts for one claim and five positive contrasts for the others.

**Observed probe output:**
```json
{
  "verdict": "contradicted",
  "contradicted": [{"context":"base","claim":"c0","role":"presence"}],
  "componentP": 0.03125,
  "holmContradictionP": 1,
  "falseContradictionProbabilityIfIndependentQ06": 0.28062267211876313
}
```

The last number is an exact conditional calculation, **not an empirical simulator result**. If the 32 claims have independent hold events, each with true hold probability `0.6`, all exceed the registered threshold. Nevertheless, the probability of at least one false contradiction is:
```js
1 - (1 - binomialLowerTail(0, 5, 0.6)) ** 32
// 0.28062267211876313
```

**Expected:** Either a multiplicity-controlled aggregate contradiction decision or an explicit label that these are unadjusted component flags without hypothesis-level error control.

**Risk/reachability:** Reaches normal `confirmHypothesis` analysis and offline reanalysis whenever multiple claims or contexts exist. It can overstate evidence against a registered design. The actual inflation depends on dependence among components; the calculation above assumes independence and does not establish an error rate for an existing study.

**Recommended next action:** Preserve raw component contradiction p-values, but adjust the family used for the aggregate contradiction verdict—or narrow the verdict’s documented meaning. The maximum-p-value intersection-union rule for **support** is not implicated.
