# M3-A advisory whole-witness cache, invalidation and exact fallback

**D61 engineering contract before code; first bounded slice of M3, not the completed indexer.** [M1/M2](README.md) own consequential verification/captured-universe exact search. This slice isolates advisory cache trust, expiry/invalidation and one bounded repair/fallback before trees/pools/segments. BACKLOG alone owns remaining work. No new live ranking, protocol quota, epoch/Model authority, public service or scientific cost study is selected.

## API and input contracts

`src/path-witness-cache.mjs` exports PathWitnessCache and PATH_CACHE_LIMITS. Constructor requires exactly `{maxEntries,maxBytes,ttlTicks}`: explicit nonnegative entry/byte capacities, positive TTL in caller-defined logical ticks. First hard software ceilings:1024 entries,1048576 bytes,1000000 TTL ticks; no defaults or calibrated TTL/time assumption. Zero entry/byte capacity disables retention, not verification/return of a valid witness. M1 exposes pathWitnessContext to normalize complete immutable expected context for this new consumer; wire/acceptance stay unchanged.

`lookup(view,context,query,{tick,hint})` requires a local immutable M2 view and matching complete M1 policy; query is the complete M2 exact-oracle epoch/search budgets. tick is explicit nonnegative safe logical time, monotonic per cache; expiry arithmetic must remain safe. No Date/time/RNG or hidden global draw offset. hint is null or untrusted canonical UTF-8 wire string; nonstring/oversized/malformed hints are rejected without coercion, never interpreted as canonical state or a no-path assertion. A string's byte bound is checked before Buffer allocation. Invalid trusted options/context/budgets/time throw before admitting the request; unexpected verifier/oracle faults propagate, not clean negative results.

## Lookup, safety and missingness

Order: expire old entries, try cached witness, try offered hint, otherwise exactly one full-view findPathWitness call with the caller's budgets. Every cached/offered positive is checked by both primary and dependency-separated ref2 **on the supplied current capture**, even when cached root matches. Disagreement throws. Root/policy/subject/epoch/TTL/live bits from the cache never grant acceptance. Decode only after both checks; retain canonical immutable data/wire, indexing all supplied candidates conservatively when an accepted slack family includes unused paths.

Fallback reuses M2's dual-verifier result bound to the same immutable capture/context/wire. No change to its found/infeasible/censored/unavailable distinction: cache miss, hint failure, expiry or evictions do not prove graph infeasibility; censored/unavailable remain feasible:null. No negative/censored/unavailable entries are cached. Search rejection is not admitted as a selected rule. This is not multiple indexers, subtree completeness or a fresh-at-use Model admission gate.

Successful cache hits do not renew TTL or alter FIFO order. TTL is fixed from a successful new hint/oracle insertion; stale rejection/expiry evicts, a successful fallback may insert repaired bytes. Expiry at tick>=expiresAt is exact. Logical ticks/schedule are caller assumptions, not protocol hours/epochs. Storage key is full domain/expected-subject/policy identity/epoch; root is retained as provenance only so a vertex-only witness may remain valid across roots after fresh checks. Query results report current root and cached-origin root distinctly, not stale authorization.

## Resource/invalidation/accounting contract

Retention is deterministic FIFO insertion (invalid/expired old entries are removed before repair), bounded by both entry count and total UTF-8 wire bytes. Oversized-for-cache valid output is returned without retention. Private maps/sets/entries never escape. Expiry scanning is O(entries) plus evicted reverse references; invalidation costs include notices and all removed references. Admission/reverse indexing is O(submitted path vertices/bytes); no O(1) cache-total-CPU or measured speedup claim. Capture/hash/dual-verifier/exact-fallback cost remain separate from cached byte counts and operator/human work.

`invalidate({edges,anchors})` is an advisory eviction notice, not authority to change live state/removal. Inputs are explicit arrays of directed edge pairs/anchor IDs, at most4096 notices per array under the first software envelope. Edge reverse index conservatively records **both orientations** of each submitted adjacent pair (overinvalidates irrelevant reverse updates in directed mode); anchor reverse index records every submitted terminal, including unused slack. Evict all matching entries and clean every reverse index on invalidation, FIFO, expiry and failed validation. A missing/dishonest notice cannot make stale paths pass: every hit still revalidates canonical liveness/removal. A malicious notice may induce extra fallback work/censorship under small budgets, not false acceptance.

`stats()` returns frozen aggregate counters/entries/bytes/reverse-key counts and last query tick; reads are inert (no expiry, renewal, FIFO movement, load/randomness change). Real lookup attempts, verifier calls, hint rejection, oracle calls, hits, expiry, invalidation, FIFO and byte/entry skips are separately accounted. This is algorithmic telemetry, not fee/XP/private utility/application usefulness. Per-query result carries source(cache/hint/oracle), normalized context/query, current root, verification/search status, TTL/origin/retention metadata and work counts. Local reference retains no personal/face data or network/request logs beyond scoped cache values/counters; public deployment/privacy/retention is not authorized.
