## Local checks, identity and resource accounting

Every put/returned lookup checks positive/simple/current vertices, enabled internal-only scores and the declared directed/any-live/reciprocal projection. Put records all live supported orientation IDs. Reuse requires original orientation continuity: any-live needs one surviving original, while directed/reciprocal require all their originals. A new opposite orientation or relation reincarnation cannot silently rebind an entry. Explicit put may retain the new incarnation, while M1/ref2 still accept the unchanged vertex-only path when current policy permits it. Required identity metadata above the software bound returns unavailable, not a graph verdict.

A WeakMap memoizes captured node/storage-ID indexes per immutable view object. The first check can scan all captured nodes and up to65536 storage rows; later hits still check current local edges/scores/references. Preparation counts, vertex/score/edge reads, reference reads/ID comparisons, checked/returned/expired/evicted/refreshed records are separate. Payload bytes cover the exact immutable JSON array only, not total process memory, bookkeeping, index fanout, shared captures or mutable counters. No linear total-CPU/state-read or speed/scaling claim follows.

FIFO/refresh/expiry/current rejection and conservative edge/vertex notices clean endpoint and reverse indexes. A returned hit increments within-cycle use and updates last verification metadata, never storedAt/expiresAt/FIFO position. Explicit refresh resets use/TTL and moves the ID to the tail. Well-formed unavailable requests still advance/sweep the logical clock; invalid data/clock/overflow throws before mutation. Lookup can perform a final safe-integer sweep. Saturation logic clips use at Number.MAX_SAFE_INTEGER with usesSaturated:true on subsequent increments; the astronomical public-operation trace to that cap is source-inspected, not exercised or presented as measured work. stats is inert. No RNG, physical clock, implicit fallback, load accounting or canonical removal occurs.
