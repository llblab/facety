## Cache-only probe contract

`cache.probe(view,context,query,{tick})` uses exactly the same complete M2 query, local immutable-view/context/policy and monotonic safe tick/expiry validation as lookup. Its query budgets normalize but are not spent. Exact request has only tick. All trusted preflight completes before admitting: update lastTick, increment existing stats.queries once, expire all due entries, check the current key's candidate with both canonical-current verifiers and exact decoded requested epoch, reject/drop if invalid, otherwise return without TTL/FIFO renewal. Do not call oracle, examine a hint, insert/refresh a value or change invalidation counters. Preserve actual cacheChecks/primaryChecks/ref2Checks/expired; hintChecks/oracleCalls are zero. A rejected candidate increases cacheRejects; a valid hit increases cacheHits.

Return frozen `facety-path-cache-probe/v1`, source:cache, with existing lookup outcome/work/cache descriptor fields. On hit use the same verified positive/context/query/current-root/old-origin/TTL data as lookup. On miss use status:miss, feasible:null, reason:cache-miss, required:null, witness:null, wire:null, stats:null, verification:null, cache retained:false and null origin/insert/expiry. An empty/unusable cache does not evaluate full-view feasibility/availability: even a missing/out-of-grace snapshot is a **cache miss**, not global false/unavailable. Cached invalidity may cause eviction, not a canonical mutation. No expiry means no free scan: its O(entries)+reverse-cleanup work is still real.

Existing stats shape stays unchanged. queries counts actual admitted cache calls, including new probes; it is not unique client requests. Existing lookup remains cache→hint→exactly one bounded full M2 if needed. No new probe counters or negative entries, no side-effect-free promise and no internal all-cache rollback is added.

## Deterministic execution, safety and actual side effects

1. Read whole-cache stats before the call. Call the native probe once with current view/context/fallback query and input.tick. On found return a normalized cache-source result; producer/finish are uncalled with null receipts, not zero completed searches. Probe alone already performed both full-current checks and requested-epoch binding.
2. On probe miss, call proposePathWitnessFromUnion exactly once with the given forest/current view/context/union query. No build/refresh/repair, segment use, route/load learning or hidden retry. C4 may find, miss, censor or be unavailable; keep its entire scoped receipt. Its nested local feasible:false never becomes top-level canonical false.
3. Read inventory before finish and call native existing lookup once at the **same tick**, same current view/context/fallback query, hint equal to C4.wire if found else null. Same-tick monotonic admission is legal. It performs a second real expiry scan/key attempt; a positive hint re-verifies on both canonical-current verifiers and retains through existing FIFO/byte/TTL rules, while no hint triggers exactly one bounded full-view M2. This is not an unchecked store API. Full fallback can found/infeasible/censored/unavailable with original true/false/null semantics. Nonpositives never retain. A later call begins with a new probe; cache hits never renew insertion TTL.

No external work interleaves in this synchronous no-callback reference. After a missed probe, C4 cannot mutate the whole cache, so finish unexpectedly returning source:cache is an invariant failure. A found C4 must finish source:hint with the exact same wire/epoch/D and current accepted primary/ref2; an advisory nonpositive must finish source:oracle with one actual full oracle call. A disagreement/schema/scope/required/decoded packet/verifier/counter violation throws rather than fabricating a report, no-path or favorable retry. Any owner calls already executed (expiry/rejection/clock/counters/retention/fallback) remain real: this API promises no atomic rollback, transaction authorization or absence of state change on exceptions.

A positive source always refers to the **full current** view and requested epoch; each chosen witness/context/D/wire must agree. Full M2 alone may supply top-level status:infeasible with feasible:false; neither probe miss nor pruned union may. Cache/forest/retained roots, tags and immutable brands authenticate neither canonical lineage nor a unique person, actual contribution, vote or funded admission lock. Caller must bind the coherent trusted supplied capture/namespace; current emergency/epoch/transaction contracts remain owner-gated.
