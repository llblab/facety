## Canonical label invariant and complete inputs

Prepare full old/current projected forward graphs and their reverse predecessor lists, using existing directed/any-live/reciprocal policy and unsigned UTF-8 ordering. Derive a complete projected-arc delta and enabled qualifying-Boolean changes, not untrusted notice completeness. Classify unaffected roots exactly as E1. Store edge-ID continuity nowhere in tree acceptance: reincarnation can miss the segment cache without changing projected paths. Root retirement never automatically removes a transit vertex.

A working label is a positive-or-zero-hop **root-first** simple path `[A,...,V]` in the current projection, hops<=r. Only internal vertices need the enabled qualifying score; A is always exempt. Label[A]=[A] is fixed. Compare labels first by hop count, then lexicographically by each whole vertex ID's unsigned UTF-8 bytes along the complete root-first path. Do not compare only parent ID, subject-first reverse paths, serialized JSON strings or mutable queue order. The canonical shortest shortlex path must agree with the existing sorted-neighbor FIFO BFS; verify that equivalence independently.

Every finite working label is a current-valid path/upper bound, but pending improvements can temporarily make its prefix differ from the current label of its parent. Do not expose such workspace as a parent tree. A successful root is exported only at quiescence after checking every nonroot label's prefix equals its parent's label, distances increment by1, all parents exist and root/hop/simple/current role invariants hold. An invariant disagreement throws; it is not a miss or false current-complete report.

## Invalidate before decreasing labels

For an affected root with a complete usable old tree, examine all its old parent records and construct old child links. For each nonroot V with old parent P, seed invalidation when the current projected P→V arc is absent, or P!=A and P no longer qualifies. Invalidate that V and **every old descendant**, deduplicating overlapping subtrees. A newly nonqualifying V may keep the path ending at V: it is V's children that lose an intermediary, not V's endpoint exemption. A deleted nonroot vertex loses its incoming parent arc through the live projection. Current-eligible root A remains fixed; absent/removed roots retire before repair.

Materialize root-first labels for old rows not invalidated, in increasing old distance with UTF-8 ties. Ancestor closure plus current parent/gate checks must make these retained paths current-valid. All invalidated labels are absent, not stale finite distances. Old children/materialization work is separately counted and bounded by old retained rows and r. This initial deletion/loss handling is mandatory: strict improvement alone cannot remove a stale path or safely break a disconnected old cycle.

For reset-all or a new target root, retain no old labels: initialize [A] only and use the same repair engine, not an implicit full-rebuild/E1 call. Reset skips old delta/classification/invalidation, with deltaComplete:false, not a claim of no change. Existing unaffected roots retain complete parent trees, subject to total node capacity, without repair queue work.

## Deterministic local queue and relaxation

Precompute the global activation-target set: destinations of added current projected arcs, plus current successors of vertices gaining eligibility when gating is enabled. This conservative shared set can include work irrelevant to an individual affected root, including a root's own qualification gain; it never changes E1's affected-root classifier. Such extra queued work is counted, not claimed necessary or free.

For an affected old root seed the sorted unique union of live invalidated vertices and activation targets. For a cold/reset root seed its current sorted successors instead. Each seed makes one schedule trial. Maintain FIFO plus a pending set; a vertex already pending is not appended twice, but may be scheduled again after it is popped. Root A is never queued. Use bounded compaction/ring storage, not an accumulating unbounded history; active pending IDs<=current live nodes. Scheduling trials include skipped root/already-pending IDs and every current outgoing neighbor considered after an update.

Pop a vertex V, charge one queue pop and remove it from pending. Start best at its existing valid label, or infinity when absent. Scan **all current predecessors** in UTF-8 order, charging every trial, including unlabeled/nonqualifying/cycle/hop-ineligible predecessors. P is a candidate only when it has a finite label, P==A or currently qualifies, appending V is simple and within r. Compare `[...label[P],V]` with best by full shortlex. Unchanged edges crossing an invalidated boundary matter; do not seed or scan only added arcs or old parents.

After a complete predecessor scan, commit only a strict improvement. Before admitting an absent label check available node capacity; before any improvement check label-update capacity. Both infinity→finite and finite shortlex improvements count, even when distance and immediate parent ID do not change. Then schedule every current outgoing neighbor in canonical order. Full ancestor-label changes must propagate through descendants; changed distance/parent tuples alone are insufficient. Root-first path arrays are bounded by r+1; no ambient RNG, queue-offset key or implicit score/load reservation is introduced.

All retained labels are current-valid and changes after invalidation strictly improve shortlex. Quiescence is the completion condition, not a claim that this has a small number of improvements. Test reachability, canonical optimality, prefix consistency and mixed-change propagation independently against raw/full rebuild/E1 before relying on it. Insertion and deletion together do not acquire an ES amortized guarantee.

## Budgets, aborts and safe publication

Visit current target roots in existing canonical order. Total maxTreeNodes bounds completed retained rows plus the active root's finite working labels; it is not cumulative allocation, old input/capture memory or full process RSS. Copied retained labels, old child maps and length-r paths still have preparation/copy cost. Every queue pop, predecessor trial, schedule attempt and strict label update consumes its separate **global** budget across all roots, including aborted work. No refunds/retries/refills occur.

Check capacity only when another operation is needed. Pop limit blocks the next pop; predecessor limit blocks the next scan trial; schedule limit blocks the next schedule attempt, including initial seeds. After a completed scan needing improvement, node capacity is checked before label-update capacity. Propagation may hit a later schedule limit after private labels changed; those updates remain counted. Exact-last exhaustion without another needed operation is not truncation. A complete unaffected root can still reuse with zero repair budgets. If no retained slot remains, omit the next root before starting work.

If a root cannot fit as a whole reused tree, omit it and later roots. If a started affected/cold root hits any limit, **discard the entire working root**, mark it aborted and omit all later roots. Never export unsettled inconsistent labels as a parent-closed complete or partial tree, silently keep stale affected rows, or run an unbudgeted E1/full rebuild. Prior fully completed/reused roots remain available. The active labels' space can be discarded, but actual work/admissions are not refunded. Missing/aborted roots are advisory unknown, not graph infeasibility. An explicitly separate caller may choose E1/full oracle with its own budget.
