## Resource limits and safe publication

Global counters span all roots, including aborted work. Every needed queue pop, predecessor scan trial, initial/propagated schedule attempt and strict update checks its own remaining budget; skipped root/pending schedules count. Node capacity bounds already completed rows plus finite labels in the active root. A current-valid old label set must fit before materialization; absent-label admission checks space before update budget. Exact-last exhaustion censors only when another operation is needed. No refunds, retries, refills or implicit fallback occur.

Whole unchanged trees that cannot fit are omitted with later roots. A started active root hitting any bound is discarded **entirely**, marked aborted, and later roots omitted. No stale affected or unsettled partial root is published. Earlier settled/reused roots remain consumable; missing roots are unknown, not graph infeasibility. Root label initialization/admitted labels/updates and queue work remain counted after discard. Tree-node-limit with no remaining slot omits the root before starting work.

Result is deeply frozen `{forest,report}`. Forest reference is `bounded-path-label-repair/v1`, current-equivalent originRoot and full current eligible anchor list; only settled/reused maps are present. Built/complete means every root settled, otherwise censored/false. Existing path/anchors/toJSON/proposal APIs consume it without exceptions to full current-path/exact-family/both-verifier checks.
