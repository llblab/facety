# M2-A immutable graph/status view

**D61 engineering contract before code, bounded local-actionable slice of M2.** [M1](m1-verifier.md) needs an actual supplied graph view before global search can be checked. This slice captures read-only DirectedGraph/Native public state; it is not the global hop oracle, event-replay engine, live epoch/ranking process, authenticated chain state or Model admission gate. BACKLOG alone owns remaining tasks. This historical M2-A checkpoint at 9dd705b predates [M2-B](m2-oracle.md), which adds global search and the factory-local isPathWitnessView brand without changing capture data/liveness rules; absent-oracle statements below describe that earlier checkpoint.

## Owners and explicit reference modes

`src/path-witness-view.mjs` exports `pathWitnessGraphView(graph, options)` and `capturePathWitnessModelView(model, options)` plus immutable software `PATH_VIEW_LIMITS`. No Model mutation is added. The first accepts an actual DirectedGraph whose nodes/edges the caller explicitly declares live (`supplied-live-directed-graph/v1`). It copies storage, never retains the mutable caller graph. The second requires FacetyModel and uses the public guarantees graph, subjects, guaranteeRelations and events only (`native-active-accepted-reference/v1`).

**Native reference predicate, not a selected WP-G live-status rule:** first require graph nodes to match all canonical subject IDs, and graph edges to match exactly one active guarantee record per endpoint pair. Proposed/ended history is retained in the capture binding but supplies no live edge; repeated pairs may have old ended records plus a new active relation. Filter the live view to protocol-public identityStatus accepted endpoints, **not** evaluator truth, XP, isActive 28d or a new verification judgment. Native invalidateIdentity leaves adjacency/active records behind; this adapter must not mistake that leftover adjacency for live accepted support. Neither identity invalidation nor a depleted/refunded bond automatically invents an authorized emergency anchor removal: that is a separate supplied list. Vouch probation expiry/custody changes do not end an otherwise active Native relation. This named current-record reference cannot silently become D34 historical liability or the final WP-G slashed/exited/duty predicate.

Node/edge injection, active-record/graph disagreement or duplicate active pairs reject capture instead of laundering direct graph edits into funded Model support. Native transitions still own consent, charges and history. The capture checks public clock/size/graph object+revision/event-count stability across reads; malformed/changed inputs throw. Arbitrary overridden getters/callbacks/proxies are not a sandbox target. Public snapshot getter work is O(history), including copying before its returned size can be checked; no cheap constant-time Native capture is claimed.

## Exact input/output contract

Options have exactly policy,currentEpoch,snapshots,removed,standing. Policy is complete M1 policy; currentEpoch is a nonnegative safe integer. snapshots is a dense array of exact `{epoch,difficulty,anchors}` records: unique safe epochs, positive D<=policy.maxDifficulty, distinct bounded scalar anchor IDs. Input order is not authority: canonicalize epoch/ID order, but reject duplicates rather than invent membership multiplicity. Future stored snapshots are allowed but M1 still rejects a future witness epoch. removed is a distinct ID array of currently authorized supplied removals. standing is a dense array of distinct `[id,nonnegative-safe-integer-or-null]` observations; omitted IDs remain unknown, never converted from XP.

**First adapter-only software ceilings:**4096 nodes,65536 edges,1025 snapshots,65536 total anchor entries,65536 Native relation records; removed/standing arrays are bounded too. These bound retained adapter data, not upstream getter allocation or a protocol quota/scaling result. M1's maxIdBytes must be at least64 for this adapter's full SHA-256 hexadecimal view token; smaller M1 profiles remain supported by custom supplied accessors, not this adapter. No hash truncation/collision shortcut or wire/policy migration is added.

The frozen view implements all M1 methods: view/snapshot/anchor/removed/edge/degree/anchorCount/standing. degree is the exact count of distinct current next-hop vertices in the requested subject-first projection: predecessor for directed-from-anchor, union for any-live undirected, intersection for reciprocal-only. Unknown subject degree is0. anchor membership is historical supplied snapshot membership; anchorCount is its current live-node intersection minus removed anchors/subject, an exact available-terminal count, not operator independence or short-route feasibility. Missing snapshot returns null/count0. Missing standing is null. No count is read from evaluator labels.

It also exposes nodeIds(), neighbors(subject,direction,projection), toJSON() and frozen capture metadata for the later global oracle and reproducibility. Arrays/records are frozen or closure-private; no mutable Map/Set/graph escapes. Invalid direction/projection throws, not fallback. Neighbor and canonical ID order is unsigned UTF-8 bytes. Degree/edge/member/eligible-count/standing reads are O(1) expected Map/Set operations after O(n+m+history+snapshot entries) capture/precomputation; sorted export costs are separate. These are operation-shape bounds, not hardware benchmarks.

A domain-separated SHA-256 commitment binds normalized policy, epoch/snapshots/removals/scores, live graph and source storage/history (including edge IDs/revision and Native relation IDs/status/timestamps). Hash is a **content binding, not authenticated canonical state**. Remove/re-add yields a new capture root even with the same current endpoint pair; M1's vertex-only witness can still pass the new live view. Immutable old captures intentionally remain old snapshots: source mutation does not refresh them. A current authorization consumer must obtain/bind a fresh capture immediately before Model-owned execution; this adapter is not that authorization or a time-of-use freshness guarantee. Captures are historical/replayable data, not a globally monotonic state service.

## Validation and remaining boundary

Test raw directed graphs exhaustively on tiny domains against independent adjacency/projection calculations; feed positive/negative witnesses through both M1 implementations. Test canonical ordering, empty/missing nodes, shortage, UTF-8/delimiter IDs, option bounds/duplicate rejection, frozen exports and input/source mutation isolation. Native tests use only funded/consented Model API transitions: proposed vs active, unilateral direction, paid end/re-proposal/re-add, public invalidation with leftover adjacency, and vouch expiry/exit if supported by the fixture. Capture itself must leave model graphs, money/XP, event sequence and source receipts unchanged. Injected graph state must fail, never acquire authority through capture.
