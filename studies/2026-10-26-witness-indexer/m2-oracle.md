## API, inputs and domain

`src/path-witness-oracle.mjs` exports `findPathWitness(view,context,query)` and immutable `PATH_ORACLE_LIMITS`. Context is exactly the complete M1 `{domain,subject,policy}`; it must match the capture's policy identity. Query has exactly `{epoch,maxExpansions,maxPaths,maxPackingSteps}`. Epoch is explicit/nonnegative/safe; no live epoch selection or difficulty recomputation. Budgets are explicit nonnegative safe integers, including zero; first software ceilings are1000000 neighbor trials,4096 retained paths,1000000 packing trials. These are bounded engineering resource limits, not calibrated cost targets, protocol quotas or performance claims.

Only locally constructed immutable M2-A views are accepted, checked by a factory-owned WeakSet brand (`isPathWitnessView`). A copied/spread/duck-typed indexer object cannot substitute a pruned/incomplete neighbor list while retaining a global-completeness claim. The brand is type/immutability provenance **inside this process**, not chain authentication or independent human/state authority. Serialization does not preserve the brand; no public JSON-to-authenticated-state promotion is added. A capture built from an explicitly pruned supplied graph is still only complete for that captured subgraph, not an omitted ledger universe. Old captures remain old; query results bind their exact root/reference/policy/context/epoch, not freshness of the original Model.

## Algorithm and completeness boundary

Preflight checks trusted query/context/capture compatibility, in-grace epoch, snapshot existence, positive adopted D, and exact captured degree/eligible-anchor count. Outside grace/missing snapshot is unavailable, not graph infeasibility. Known degree or eligible count<D is a sufficient structural infeasibility proof and needs no search budget. No zero-D or anchor-self exemption is introduced.

Enumerate every admissible positive-length simple subject-first path of at most r edges using byte-ordered captured neighbors and a per-path visited set. An anchor may be a terminal and still be continued through as transit; no terminal-only-core rule is added. Terminal needs snapshot membership, nonremoval and different subject. Optional score is required **only to continue a non-subject node as an intermediary**, not to end at it. Removed anchors may still be transit if their current edges/standing permit; emergency removal means ineligible terminal, not invented edge deletion. Directed predecessor/undirected any-live/reciprocal projection comes from M2-A, not a hop-layer capacity trick.

A neighbor trial consumes one expansion before cycle/score filtering; a discovered admissible path is retained only if path capacity remains. The exact last permitted trial/path is not automatically censoring: halt only when additional required work/candidate would exceed a cap. Store paths in deterministic DFS discovery order. Then recursively try all D-combinations with a shared non-subject occupied-vertex set, endpoints included. A packing trial consumes one step before trying a candidate; a Dth successful trial at the exact cap may finish. No greedy first-fit rejection, BFS-tree pruning, ordinary unbounded flow or duplicate per-layer person capacity is used.

Packing also runs on a partially enumerated prefix: a valid D-family is positive evidence even when enumeration was interrupted. If no family is found, structural infeasibility requires complete enumeration **and** complete packing, except the necessary preflight/count proofs. CPU is exponential in the declared domain in the absence of budgets; retained path storage is O(maxPaths*r), packing depth<=D<=64, path depth<=r<=64. Counters bound algorithmic neighbor/candidate trials, not all hashing/byte/Map work, capture cost, physical hardware latency or human work.

## Results and trust boundary

Result is frozen serializable data: status(found/infeasible/censored/unavailable), feasible(true/false/null), reason, viewRoot/reference, normalized context/query, required D, witness/null, canonical UTF-8 wire string/null, stats(expansions/retained paths/packing trials and separate phase-completion flags) and verification/null. Phase flags mean exhaustive enumeration and exhaustive packing on the retained pool; a positive need not exhaust either phase. No mutable Buffer escapes; callers use Buffer.from(result.wire,'utf8') for M1 APIs.

Every found family is encoded under the original context and must pass **both** primary and dependency-separated ref2 on the same capture before return. An implementation/verifier disagreement throws; it is not converted into censored/infeasible. Returned witness is canonical/frozen data, exactly D paths, not a maximum/shortest/minimum-cost family or a quota. The algorithm is deterministic for the same implementation/capture/context/query; no RNG/seeds/draw-layout changes.

If a found structural family cannot fit the software wire byte cap, return censored/witness-byte-bound, not graph infeasible. A different family might fit; no wire-size optimizer or transport-feasibility completeness is claimed. Invalid trusted inputs/unsupported budgets/policy mismatch throw. Search caps return censored with feasible:null; outside grace/missing snapshot returns unavailable with feasible:null. None may be counted as safe/no-attack or no-path. Reasons/phase flags distinguish enumeration limit, packing limit, path retention, wire limit and an exhausted negative. Positive results on a partial prefix keep enumerationComplete:false.
