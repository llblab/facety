# M3-A whole-witness cache requested-epoch correction

**2026-10-26 · correctness follow-up to671f2db; separate from the frozen [M3-A contract/history](m3-cache.md).** During preparation of cache/advice/full-fallback integration, existing lookup exposed a consumer-scope defect: M1/ref2 accept a valid packet for its own epoch within grace, but #check attached the caller's different query.epoch without comparing it to decoded witness.epoch. An epoch2/D1 packet could therefore be reported/retained under an epoch3/D2 key (or an absent/out-of-grace/future requested epoch). This is not a malformed/unsound M1 packet, a verifier bug, an adopted-D/grace policy choice or a demonstrated Model-funded admission failure; it is disagreement between the request/result/key and actual verified snapshot.

## Correction contract before source change

Keep the existing lookup API, query normalization, cache→hint→one exact-fallback order, TTL/FIFO, reverse indexing, schemas and counters. In the shared cached/offered-wire check, after both current-capture verifiers accept and before constructing a positive result/retaining a hint, decode once and require witness.epoch===query.epoch. A mismatch returns the ordinary rejected-candidate sentinel; hintRejects/cacheRejects and actual verifier work remain the existing units. Continue at the normal bounded full-view oracle for the **requested** epoch; preserve its found/infeasible/censored/unavailable/true-false-null status and do not cache nonpositives. Matching epochs retain byte-for-byte result/accounting semantics. Shared checking also protects any wrongly scoped entry if one were ever supplied by an older internal path; no persisted cache import or migration exists.

Do not instead relabel query/required to the hinted epoch, widen grace, select current difficulty, skip dual verification, throw a trusted-config error for an untrusted hint, or let a caller choose a weaker in-grace snapshot by mislabeling its request. Packet validity and exact API-request scope are separate. This follows M3-A's epoch-keyed query/M2-result contract; it selects no live authorization/transaction epoch rule or new protocol quorum/ranking/Standing/capacity/default policy.
