# Shared-target invitation evidence: software checkpoint

**Implemented counterfactual, not a new outcome study.** D44's [F51 comparison](../2026-10-24-attended-comparison/README.md) relies on supplied independent errors. This bounded follow-up adds an explicit common-mode environment control without changing the default, protocol authority/economics or prior packets. It does not establish real detector covariance, measured human behavior, genuine-harm safety or a mechanism.

## Contract

`runExperiment({ invitationEvidence: 'shared-target' })` selects one persistent first-stage identity signal per public pending target across invitation reviewers/times. Default `independent` retains the exact old `[targetId, context]` key. Both use the same supplied marginal `sensitivity`/`falsePositiveRate`; stable target class is an environment assumption. Shared mode uses `['invitation-shared-target-v1', targetId]` under `new Random(seed).fork('observations')`. A repeated ID, including another invitation to it, keeps its key; a different ID has a distinct key, not verified independent personhood. Switching modes changes keys/received signals even at a shared first-look time; only nominal single-look quality is matched. This is an extremal common-mode stress reference, not a calibrated shared-media model.

The [environment owner](../../src/identity-observations.mjs) is a nine-line, import-free factory with a direct software-test seam; the scheduler wires it, without widening the experiment facade. It emits only a frozen `suspicious` boolean. Declared identity class remains inside the environment/evaluator; it is not supplied to defense or `FacetyModel`. Other observation contexts, guarantee vetting, ordinary Self-ID inspection, verification and dispute procedures retain their references. Optional verification is attempted only after a positive first stage, as before; independence/authenticity of those other channels is not proven.

Every look still incurs paid inspection work; sharing never creates free notification or evidence. Daily trials, attention, optional verification, transaction/work gates, directed authority, strict expiry and effect ablation are unchanged. No future calendar, extra retry, budget refill, liability-derived vigilance, new sanction or selected protocol/default rule is introduced. `shared-target` is valid on 24/6/4-hour clocks but does not activate review activity or fix the default-daily eligibility gap. Full manifests add `invitationEvidence: shared-target-first-stage-v1`, independently composable with first-attended and D45 dispute markers. Output assumptions replace the independent-noise statement and sub-day evidence text names this counterfactual.

The [model contract](../../docs/simulator.en.md#shared-target-evidence-counterfactual) owns assumptions; [experiment docs](../../docs/experiments.en.md#observation-and-defense-boundary) own API use. [Example](../../examples/shared-invitation-evidence.json) is illustrative, not research calibration.

## Software evidence

[`test/identity-observations.test.mjs`](../../test/identity-observations.test.mjs) has five families:

- Keys, class-specific probabilities, immutable observations and pending-target injection. Eight quality/class partitions × 128 software seeds check persistence across observer/time contexts and separate target keys; distinct bits are not required for different targets.
- Validation, unchanged independent manifests on all clocks and joint evidence/first-attended/regular-dispute manifest binding, including mixed-arm registration transport.
- Paid native review/evaluator counts against a separate fixed-clique time/key oracle for both descendant classes, both evidence modes and 4/6-hour clocks; effect-disabled native states remain matched despite changed signals/work.
- Work denial, optional verification, transaction availability, authority/window and veto-effect prefix checks.
- Inert-inspection and future-attention-prefix controls.

These are software fixtures, not population trials; no planned research labels/capture method were run. No independence, media authenticity, useful growth, real attack cost or endogenous willingness is inferred.
