## Delivered

- `src/sponsor-assessment.mjs`: `assessSponsorship(evidence, profile)`, explicitly named `two-outcome-private-utility-v1`. Received positive/distinct-tag, positive/shared-tag, negative or missing evidence selects an observer-supplied subjective prospect. All beliefs/payoffs are supplied, no hidden personhood/act validity/target-intent input or automatic human baseline.
- The conditional difference is `p × upheld + (1 − p) × rejected + participation − workCost − abstain`, in caller-declared common **private utility**, not FACY, XP, human time or welfare. It is a prospective comparison for a supplied hypothetical outcome menu, **not actual expected payoff from the currently blocked executable act-case path**. No remedy or external effect is justified by entering a number.
- Strict positive/negative differences produce conditional willingness/refusal; ties and active missing values remain undetermined. Zero-probability missing outcomes need no imputation; otherwise unknown prospects propagate conservatively. Finite IEEE-754 arithmetic is checked without tolerance. The observer's goal is descriptive: changing a label alone cannot change a decision.
- `relay.sponsor(actor, packageId, profile)` opts into a paid act-defect `sponsor-decision`, retaining assessment, actual XP/stake access, reviewed/open route, eligible willing request reaching the existing case-contract guard (`attempted`) and actual case opening separately. Willingness does not grant authority, open a case or remove the identity-enforcement guard. Associated route receipts survive tracing off; an unfunded decision has no receipt and a null visible assessment. The no-profile call remains the old scripted control.
