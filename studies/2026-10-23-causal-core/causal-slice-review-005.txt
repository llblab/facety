## Supported findings, ranked by concrete impact

### 1. Medium — Public actor arguments can select the privileged, budget-free adjudicator path

**Evidence:** `src/accountability.mjs:105–113`, with public callers at `118–155`.

`#act` treats `actorId === null` as an internal adjudicator and bypasses actor lookup and budget charging. Public `observe`, `package`, and `route` methods forward their actor argument without rejecting that sentinel.

**Smallest reproduced sequence:** Construct a relay containing only a zero-budget Bela actor, then:

```js
const o = relay.observe(null, acts.Mira, {
  suspicious: true, sourceGroup: 'media',
});
const p = relay.package(null, [o.value]);
const r = relay.route(null, p.value, 'Bela');
```

Actual output:

```text
observe: ok=true, work=0
package: ok=true, work=0
route:   ok=true, work=0
Bela: spent=0, denied=0
```

All three trace records identified the actor as `reference-adjudicator`.

**Risk:** An unregistered input can create and circulate evidence without consuming any declared work account. This breaks the bounded-input/work-budget contract and produces misleading actor provenance. It does not bypass the sponsor’s subsequent XP/stake gate.

**Recommended next action:** Require registered actors at every public actor-taking entrypoint. Keep adjudication’s privileged execution path internal and inaccessible through the same caller-controlled sentinel. Add a regression asserting that `null` actor inputs produce no records, routes, or work-state changes.

### 2. Medium — A valid numeric-boundary verdict can partially mutate state, escape the journal, and permanently strand its case

**Evidence:**

- `src/accountability.mjs:212–217`: Stake settlement precedes enforcement and case closure.
- `src/disputes.mjs:36–45`: Liable parties are penalized sequentially.
- `src/model.mjs:434–448`: Aggregate debt overflow throws before the current penalty is applied.
- `src/accountability.mjs:44–51`: Non-`ProtocolRejection` exceptions escape before a journal record is created.

**Reproducer:** Use `causalWorld()`, normalize these accepted dispute overrides through `experimentConfig`, then observe/package/route/review/sponsor Mira through Bela and resolve upheld:

```js
{
  enabled: true,
  stakeBacking: 'reserved',
  fineMode: 'fixed',
  fine: Number.MAX_SAFE_INTEGER,
  liability: 'inviter-chain',
  rewardShare: 0,
}
```

Actual output:

```text
RangeError: aggregate debt must be an integer >= 0
```

Observed aftermath:

```text
Stake: settled; reserved 1 FACY released
Mira: penalty applied, collected=1, debtAdded=9007199254740990
Journal records: 5 before, 5 after
Relay case: resolvedAt=null, upheld=null
Stake summary: openCases=0
Retry: ok=false, reason="stake case is not open"
```

**Risk:** The API throws without recording the partial enforcement. Custody and one penalty have already changed, but the relay still advertises an unresolved case which cannot complete on retry. This is an extreme accepted configuration, not a failure observed in the ordinary examples.

**Recommended next action:** Preflight arithmetic for the complete verdict before settlement/mutation, or reject unsafe configurations before opening the case. Preserve explicit failure evidence if an enforcement operation nevertheless throws after mutation. Add this boundary regression; do not solve it by swallowing programming errors.
