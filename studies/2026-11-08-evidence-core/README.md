## A: repeat-observation dependence (registered before local runs)

The last fixes a target's observation across examiners and days. Single-look marginals match; two-look filing is `p²`, `p*(0.5+0.5*p)`, p and p respectively. The last column is not loss already suffered. No Treasury or later creditor payment converts it into a future reward. The zero-backed example refutes automatic funding of defense by the advertised ladder prize: even a certain winner receives zero additional FACY. At positive effort cost, willingness requires some separate account value, reciprocity, social benefit or funding; none is priced here. This is an incentive dependency, not permission to add a financial admission barrier.

For private utility, choose a common supplied utility unit. Let G be the incremental benefit of misconduct relative to the comparison action, C the valued actually collected loss including later repayment, E valued incremental private effort, and V additional forfeited continuation value **excluding repayments already counted in C**. Deterrence requires `G <= C + E + V`; no positive V is assumed for an account its controller abandons. Without supplied valuations, only the monetary ledger is numeric; unvalued effort is not added to FACY. For a defender, expected **collected** reward and supplied external benefits must cover effort plus expected monetary/continuation loss without double counting. Returned principal is excluded. These are conditional accounting inequalities, not a fitted utility model or an equilibrium.
